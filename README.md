# Football Simulator

## About the Project
Football Simulator is a web application designed to simulate football leagues, seasons, and tournaments. 
**Please note:** This project is currently in active development. The ultimate goal of the project is to provide a fully functional engine capable of simulating matches between different teams.

## Tech Stack
### Frontend
* **Framework**: Angular.
* **UI Library**: PrimeNG.
* **Architecture**: Modular structure utilizing Reactive Forms and Event-driven communication.

### Backend
* **Framework**: Python with FastAPI.
* **Database**: PostgreSQL (using direct SQL queries via `psycopg2`).
* **Data Validation**: Pydantic models (DTOs).
